# Zev Ambient — Codex Handoff Bundle

Use `ZEV_AMBIENT_CODEX_SPEC.md` as the master specification.

For the lowest-friction start:
1. Put this bundle in the directory where you want the project.
2. Start Codex CLI in that directory.
3. Paste the contents of `CODEX_BOOTSTRAP_PROMPT.txt` once.
4. Codex should create/maintain the actual repository and proceed autonomously.

`AGENTS.md` is included so Codex retains compact standing instructions across sessions.
