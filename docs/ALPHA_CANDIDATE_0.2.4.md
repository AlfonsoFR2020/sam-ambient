precautionary hold on unreproduced intermittent voice and aesthetic complaints.

release task now authorizes publication after exact-commit checks; native remains
unavailable. No second human beta.

## Build disposition / actual blocker

Wheel and sdist build with the existing offline toolchain. The directory frozen
companion builds and passes authenticated smoke; its ZIP is private unsigned dev
material. `dist/SHA256SUMS-0.2.4.txt` inventories the successful local artifacts.

**Windows installer build blocked by host execution failure.** Rust/MSVC compilation
starts, but Cargo cannot execute generated `build-script-build` helpers for
parking_lot_core, getrandom and zmij: Windows access denied (OS error 5). Expected
alias is absent while the hashed compiler-produced EXE remains. Exact security/
filesystem cause is not established; no AV bypass/whitelist/global configuration
change was attempted. No NSIS installer or installed/native-shell smoke passed.
This is a packaging/environment blocker, not evidence of a Sam conversation defect.

Other tooling facts: an isolated cx_Freeze MSVC-cache miss aborted through OpenSSL;
copying the existing redistributable cache to its correct isolated location allowed
the unchanged packager to finish. Initial pnpm wrapper tried reinstalling modules;
the guarded script now invokes existing local Tauri/TypeScript/Vite tools directly,
without dependency changes. Preserve fresh BuildRoot/refuse-overwrite and explicit
unsigned-development authorization guards.

**Minimum completion:** on a Windows build host that permits legitimate Cargo
helpers under its security policy, rerun the guarded same-version installer build.
Then close the separately stale package smoke through the actual native owner
UI/private proof path (never the old unauthenticated socket), installed persistence/
shutdown checks and artifact manifest. No voice/visual research programme is needed.
Public installer additionally requires signing/reputation checks. Until then native distribution remains unavailable. This does not block the
separately authorized source/Python pre-release under the final release policy.

speech, installed voice pleasantness, conservative interruption, Orb softness/
membrane/embodiment and Console/Memory presentation remain experimental. Artistic
redesign, serious STT modernization and refined persona settings remain later.
